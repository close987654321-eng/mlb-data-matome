- 2026-08-23 型④第3号（一度も追いついてないのに、1位に戻ってた）: 定点の第3号は**動いた数字でなく動かなかった数字で立てた**。
  前2号が順位の入れ替わりを追う構成だったので、同じ手を3回やると読み比べにならない。今回は3章すべてを
  「止まっている数字」で揃えた（大谷の投手欄が7/27のスナップショットと一文字も違わない／投手WARが51日間3.0で水平／
  山本が26回投げてスコア0.1）。**定点は号ごとに"何を見るか"の軸を替えると続く**。
  - ★**同じ4週間を3つの自前データで見ると、答えが割れることそのものが章になる**。MVPボードの1位は替わったのに
    WARの差は一度も0.8を切っていない（配合＝打撃0.5/WAR0.25/本塁打0.15/走塁0.05/守備0.05）。
    どっちが上かでなく**何で測るかの話**に着地させると、x-post の「評価軸そのものを疑うと読者が持論を出せる」と同じ開き方になる。
  - ★**日次の差分は git のボードJSON履歴から機械的に取れる**（前号で確立した手を拡張）。
