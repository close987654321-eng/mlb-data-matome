# matome フィードバック蓄積ログ

このファイルは matome スキルが「使うほど育つ」ための学習メモ。
村山が個々のまとめ記事に出したダメ出し・好み・刺さったパターンをここに溜める。
スキルは**編集を始める前にここを読んでセルフレビュー**し（手順 Step 0）、**保存後に新しい学びを追記**する。

SKILL.md の R1〜R7 が「確定した編集ルール」なら、このログは**その手前のメモ**：
まだルール化していない細かな好み・1回限りかもしれない指摘を貯める場所。
同じ趣旨が2回来たら、それは R番号ルールに昇格させる合図（SKILL.md 側へ移して `【強】` 相当に）。

書き方のルール：
- 1項目 = 1行〜数行。具体的に。「この記事の○○がダメだった → 次はこうする」の形で。
- 競技固有なら `（mlb）`、シリーズ固有なら `（dodgers）` を添える。
- 「それ記録しなくていい／その記事だけの話」と言われたものは書かない。
- ルールに昇格させたら、ここからは消して SKILL.md の R番号に移す（二重管理しない）。

## シリーズ / インタビュー（R6/R7）

- 看板シリーズ（dodgers 等）の試合動画は、コメント欄が試合経過ではなく**特定選手の罵倒一色**でも
  シリーズ記事にする（2026-06-21・dodgers）。タッカー叩き回（House of Highlights のドジャースvs
  オリオールズ）を、内容が watch-along らしくないからと単発YouTube記事にしたら「ドジャースニキ
  シリーズにして」と指摘。→ 自軍の試合ハイライト動画なら原則 `series` を付ける（定型タイトルに
  上書きされ選手名フックは消えるが、毎試合の連続性とバッジ/`/watch` 掲載を優先）。
- 試合の日付（`id` の日付プレフィックス＋`series.date`）は**日本時間（JST）の試合開始日**で書く
  （2026-06-16・mlb）。米国夜のゲームは JST だと翌日になるので、MLB 公式ハイライトのタイトルに
  入っている**米国日付（例: "(6/15/26)"）をそのまま使わない**。例: 米6/15 夜の試合 → `id`/`series.date`
  は `2026-06-16`。`fetchedAt`（取得時刻）は実際の取得日時のままでよい（試合日とは別物）。
- 番組セグメント（MLB Network『MLB Central』等）の動画を記事化するとき、動画とコメントの間に
  キャスターの会話を入れたいと要望（2026-06-14・mlb）。→ Thread に `transcript`（`{ja, en?, speaker?}[]`）
  を追加。動画→`transcript`（「番組での会話」見出し）→海外ニキのコメント、の順で表示される。
  発言者が特定できないときは `speaker` 省略・`ja` だけでよい（捏造しない）。コメントの並びは
  通常どおり R1/R2/R4。番組のオチ（解説者ジョーク等）をコメントのオチで拾うと締まる。
